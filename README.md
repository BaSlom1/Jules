# ЧЗХ? (Что За Хрень?)

Полноценное десктопное приложение-утилита для Windows, которое интегрируется в контекстное меню проводника.
При нажатии ПКМ на файл или папку, программа собирает локальную информацию (размер, даты, метаданные PE файлов, SHA-256) и отправляет запрос к бесплатному AI-интерфейсу (pollinations.ai), чтобы объяснить простым языком, что это такое и можно ли его удалять.

**Без платных API.** Все запросы идут с локального устройства через бесплатный открытый API.

## Как установить (Готовый .exe)

Проект автоматически собирается в один исполняемый файл `.exe` через GitHub Actions.

1. Перейдите во вкладку **Actions** в репозитории на GitHub.
2. Откройте последний успешный запуск workflow ("Build CHZH Executable").
3. В самом низу, в разделе **Artifacts**, скачайте архив `chzh-executable`.
4. Распакуйте скачанный архив.
5. Запустите `chzh.exe` двойным кликом. Откроется окно настроек.
6. Нажмите **«Добавить "ЧЗХ?" в меню ПКМ»**. Теперь вы можете вызывать утилиту кликом правой кнопкой мыши по любому файлу или папке!

## Запуск проекта локально (для разработчиков)

Если вы хотите запустить исходный код или собрать проект самостоятельно:

1. Склонируйте репозиторий.
2. Убедитесь, что у вас установлен Python (версии 3.10+).
3. Установите зависимости:
   ```cmd
   pip install -r requirements.txt
   ```
4. Запустите приложение в режиме настроек:
   ```cmd
   python src/main.py
   ```
5. Для ручного тестирования на конкретном файле/папке:
   ```cmd
   python src/main.py "C:\путь\к\вашему\файлу"
   ```

## Сборка .exe вручную

```cmd
pyinstaller --noconfirm --onefile --windowed --name "chzh" src/main.py
```
Скомпилированный файл появится в папке `dist`.

## Особенности
- **Темная тема:** Современный и минималистичный UI на базе CustomTkinter.
- **Безопасность:** Внедрение в меню ПКМ происходит в реестр текущего пользователя (`HKCU`), поэтому **права администратора не требуются**.
- **Локальный анализ:** Хэширование, извлечение PE-метаданных (`pefile`), расчет размеров папок.
